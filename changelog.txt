* Fixed: Czech translation of "Update Log" changed from "Protokol aktualizací" to "Záznam aktualizací" for consistency

* Fixed: Update type filter labels (Core, Plugin, Theme, Translation) are now translatable

* Initial public release
* Logs all WordPress core, plugin, theme and translation updates
* Tracks old/new version, method (auto/manual), status (ok/fail)
* Detects update importance (major/minor/patch) via semver comparison
* Admin log page with type and date filters, pagination, responsive layout
* Multisite support (single shared table across the network)
* Czech (cs_CZ) translation included
